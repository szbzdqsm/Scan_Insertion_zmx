## rewire

### JsonConfig
```Json
{
  "briefInfo": "rewire",
  "description": "Rewires the current design.",
  "isAtLeastOneArg": false,
}
```
### Argument

None

### Description

This command is used to move the wire "input and output directly connected" or "output and output directly connected" to the upper level and do merge to reduce the assign statement.

### Example

Scenario : The following example rewires the current design.

```
rewire
```
